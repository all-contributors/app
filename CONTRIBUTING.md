# Contributing

Thank you for your interest in the all-contributors bot! We welcome all
kinds of contributions, from bug reports and ideas to docs and code.

For an overview of how to contribute across the All Contributors projects,
see the
[All Contributors contributing guide](https://allcontributors.org/en/project/contribute/).

## Before you contribute

* **Please open an issue before you open a pull request here in the app director.** We want to talk
  with you about your idea first. This applies to every change in this
  repository, even small ones. You can browse
  [open issues](https://github.com/all-contributors/app/issues) or
  [open a new one](https://github.com/all-contributors/app/issues/new/choose).
* **We want to talk with a human.** You're welcome to use AI tools, but a
  person needs to open the issue, understand the change, test it, and
  respond to review. We will close issues and pull requests that are
  generated entirely by an AI agent.
* **Please be respectful.** Everyone who takes part in this project agrees
  to follow our [Code of Conduct](CODE-OF-CONDUCT.md).

## Make a change

Once we've agreed on a change in an issue:

1. Fork this repository and create a new branch.
2. Keep your pull request small and focused on one change.
3. Run `npm test` and `npm run lint` before you push.
4. Open a pull request and link it to your issue.

* To set up your environment and run the tests and linter, see
